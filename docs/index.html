ipaas-mcp-server

Pré-requisitos

O que você precisa antes de rodar o servidor MCP do TOTVS iPaaS.

Selecione seu sistema operacional

1

Node.js 20 ou superior

O servidor roda em Node e é iniciado via npx.

Baixe o instalador LTS em nodejs.org ou use o winget:

winget install OpenJS.NodeJS.LTS

Baixe o instalador em nodejs.org ou use o Homebrew:

brew install node

Use o nvm (recomendado) para instalar e fixar a versão 20:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
nvm install 20

Verifique: node --version deve mostrar v20 ou superior.

2

Um host de LLM com suporte a MCP

3

Ambiente gráfico para o login

O login no iPaaS abre uma janela do Chromium (baixada automaticamente na primeira vez).

Funciona direto. Nenhuma configuração adicional é necessária.

Em redes corporativas (proxy/firewall com inspeção TLS), o download automático do Chromium pode falhar com erro de certificado. Nesse caso, defina IPAAS_USE_SYSTEM_BROWSER como true para usar o Chrome/Edge já instalado no Windows (tenta Chrome, depois Edge, depois o Chromium do Playwright). A sessão continua isolada — não usa o seu perfil pessoal: 

{
  "mcpServers": {
    "ipaas": {
      "command": "npx",
      "args": ["-y", "ipaas-mcp-server"],
      "env": { "IPAAS_USE_SYSTEM_BROWSER": "true" }
    }
  }
}

Funciona direto. Nenhuma configuração adicional é necessária.

Em desktop (X11/Wayland) o display é detectado automaticamente. Em ambiente headless (SSH, container, sem interface gráfica) o login manual não é possível — rode o servidor numa máquina com desktop.
