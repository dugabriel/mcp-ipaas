ipaas-mcp-server

Servidor MCP (STDIO) para automatizar e monitorar o TOTVS iPaaS.

Pré-requisitos & instalação

Pré-requisitos

⬢

O servidor roda em Node e é instalado via npx. Baixe em nodejs.org. Verifique com node --version.

🤖

Qualquer cliente que fale o Model Context Protocol: Kiro, Claude Desktop, OpenAI Codex, OpenCode, entre outros. Escolha o seu abaixo.

Login gráfico: o login no iPaaS abre uma janela do Chromium (via Playwright), baixado automaticamente na primeira vez. Funciona direto no Windows e macOS; no Linux desktop o display é detectado automaticamente. Em Linux headless (SSH/container, sem interface gráfica), o login manual não é possível — use uma máquina com desktop.

Adicione o servidor ao seu host

Kiro

Workspace: .kiro/settings/mcp.json · Usuário: ~/.kiro/settings/mcp.json

Cole este bloco no arquivo (dentro de mcpServers):

{
  "mcpServers": {
    "ipaas": {
      "command": "npx",
      "args": ["-y", "ipaas-mcp-server"]
    }
  }
}

Claude Desktop

macOS: ~/Library/Application Support/Claude/claude_desktop_config.json · Windows: %APPDATA%\Claude\claude_desktop_config.json

Adicione a entrada em mcpServers e reinicie o Claude:

{
  "mcpServers": {
    "ipaas": {
      "command": "npx",
      "args": ["-y", "ipaas-mcp-server"]
    }
  }
}

OpenAI Codex CLI

Arquivo: ~/.codex/config.toml

Opção A — adicione esta tabela ao config.toml:

[mcp_servers.ipaas]
command = "npx"
args = ["-y", "ipaas-mcp-server"]

Opção B — pela linha de comando:

codex mcp add ipaas -- npx -y ipaas-mcp-server

OpenCode

Projeto: opencode.json · Global: ~/.config/opencode/opencode.json

Adicione a entrada em mcp:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "ipaas": {
      "type": "local",
      "command": ["npx", "-y", "ipaas-mcp-server"],
      "enabled": true
    }
  }
}

Primeiro uso

Depois de adicionar e reiniciar o host, chame as tools nesta ordem para autenticar:

  1. iniciar_login_ipaas — abre o navegador; faça login e selecione a empresa.
  2. confirmar_empresa — captura e valida a sessão.
  3. status_sessao — confirma que a sessão está ATIVA.
